# 信号扫描规则

拿到完整数据后，逐家公司逐条扫描以下规则：

## 1. 首创性声明信号

- 出现 "world's first" / "first to" / "first-ever" / "pioneering" / "groundbreaking"
  - 结合上下文判断属于技术突破、产品定义创新、还是新品类开创
  - 标记为 "首创性声明（技术突破）" 或 "首创性声明（产品/品类创新）" 等，优先级: 极高
- 出现 NeurIPS / ICML / CVPR / ACL / ICLR / EMNLP + paper/presentation
  - 标记: "顶级会议论文", 优先级: 极高

## 2. 业务信号

- 出现 "partner with" / "integration with" + 大厂名（Google/Microsoft/AWS/OpenAI/Anthropic）
  - 标记: "大厂/独角兽合作", 优先级: 极高
- 出现 "3x ARR" / "doubled revenue" / "120% YoY" / 具体增长率 >15% MoM
  - 标记: "ARR 高增速", 优先级: 极高
- 出现 CB Insights / Gartner / Forrester
  - 标记: "行业机构认可", 优先级: 高
- 获得知名客户 / case study 中大客户 logo
  - 标记: "知名客户验证", 优先级: 高
- 技术博客/开源项目 high stars / forks
  - 标记: "开发者社区影响力", 优先级: 中
- 发布开源项目或标准提案
  - 标记: "行业影响力建设", 优先级: 中

## 3. 资金信号

- funding_stage == "Seed" 或 "Pre-A"
  - 标记: "下一轮窗口即将打开", 优先级: 高
- 距离上轮融资超过 18 个月
  - 标记: "可能急需新一轮融资", 优先级: 高
- 融资金额显著增长
  - 标记: "市场热度上升", 优先级: 中
- 尚未融过资（bootstrapped）
  - 标记: "早期机会（风险较高）", 优先级: 视情况

## 4. 团队信号

- 创始人背景中出现 Google / Meta / Microsoft / OpenAI / Stanford / MIT 等
  - 标记: "大厂/名校背景", 优先级: 高
- 员工数月环比增长 >20%
  - 标记: "团队快速增长", 优先级: 高
- 新招关键岗位（CTO/VP Engineering）
  - 标记: "能力补强信号", 优先级: 中
- 创始人多次创业
  - 标记: "多次创业经验", 优先级: 视情况

## 5. 赛道信号

- 整个名单中近 90 天内有 3+ 家完成融资
  - 赛道整体标记: "赛道热度极高"
- 大厂刚进入该赛道
  - 标记: "赛道被验证，竞争加剧", 优先级: 高
- 行业出现标杆性并购 / IPO
  - 标记: "估值锚定点出现", 优先级: 高
- 政府出台相关政策 / 监管变化
  - 标记: "政策利好或风险", 优先级: 中

每家公司的最终优先级 = **所有匹配信号中的最高级别**。

信号级别标识: 🔴 极高 / 🟠 高 / 🟡 中 / ⚪ 低
