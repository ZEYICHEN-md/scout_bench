# 投资分析报告模板

文件名格式: `company_mining_report_{赛道名}_{日期}.md`

赛道名用简短英文（小写下划线），日期为 `YYYY-MM-DD`。

## 完整 Markdown 模板

```markdown
## [赛道名] 公司挖掘报告

> 扫描时间: YYYY-MM-DD | 最终候选: X 家 | 高优先级: X 家
> 数据来源: Exa Websets + 补充搜索

---

### 高优先级公司（2+ 信号）

#### [公司名](官网)

**1. 这家公司是做什么的？**

用 1-2 句话简洁说明: 公司做什么产品、解决什么问题、目标客户是谁。

**2. 什么触发信号让他被挖掘出来？**

列出所有匹配的信号，附来源链接:
- [具体信号描述](来源URL)
- [具体信号描述](来源URL)

**3. 亮点是什么？（团队 / 技术 / 产品 / 商业）**，附来源链接

- **团队**: 创始人背景、大厂/名校经历、核心成员
- **技术**: 技术壁垒、专利/论文/开源项目
- **产品**: 核心产品/功能、与竞品差异
- **商业**: 客户、收入、增长数据、合作伙伴

**4. 关键信息**

| 维度 | 详情 |
|------|------|
| 创始人 | [姓名] — [前公司] [职位] [LinkedIn](URL) |
| 创始人背景 | [根据华人限定状态显示: 华人确认/华人可能/不限/未确认] |
| 总部 | [城市, 国家] |
| 成立 | [年份] |
| 融资轮次 | [轮次名]，[年月] |
| 总融资 | $[X]M |
| 估值 | $[X]M（如有公开数据） |
| 投资机构 | [列出已知的投资方] |
| 领投方 | [轮次]: [领投方名称] |
| 其他链接 | 公司[LinkedIn](URL) 创始人[LinkedIn](URL) |

---

### 中优先级公司（1 个信号）

#### [公司名](官网)

**1. 这家公司是做什么的？**
[1-2 句]

**2. 什么触发信号？**
- [信号列表]

**3. 亮点**
[简要要点，团队/技术/产品/商业有则写]

**4. 关键信息**

| 维度 | 详情 |

| 创始人 | [姓名] [LinkedIn](URL) |

| 其他链接 | [...] |

### 待观察（无明显信号）

| 公司 | 创始人 | 背景 | 融资 | 简介 | 链接 |

### 赛道全景

- **赛道公司总数**: X 家
- **融资阶段分布**: Pre-seed X 家 / Seed X 家 / Series A X 家
- **地域分布**: [城市] X 家 / ...
- **近期融资情况**: 近 90 天 X 家完成融资
- **赛道热度**: [高/中/低] — 近 90 天 X 家融资
- **近期大事**: [1-2 句]

> 所有信源均可追溯，点击链接即可查证。如需导出 CSV 或深入调研某家公司请告诉我。
```
