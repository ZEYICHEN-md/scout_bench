# 学术引用投资Brief生成Skill

通过爬取Google Scholar学者主页，分析创始团队学术 footprint，生成结构化投资Brief。

## 输入格式

用户提供按公司分组的人员列表。

每人必须提供：
- **姓名**（最好是Google Scholar上使用的名称）
- **公司**
- **背景提示**（可选但有助于定位：学校、导师、代表作等）

用户**必须明确说明**哪家是**标的公司**，哪些是**竞对公司**。如未说明，先询问再执行。

## 输出格式

生成单个markdown文件，结构**严格参照** `references/output_template.md`。报告必须包含：
1. 核心洞察，含**三条必备排名语句**：
   - `学术总引用量：[Company C]（XX万）>> [Company B]（XX万）> [Company A]（XX万）`
   - `一/二作顶会顶刊引用量：[Company C]（XX万）>> [Company B]（XX万）> [Company A]（XX万）`
   - `学者研究方向与创业路线相关性：[Company A] > [Company B] > [Company C]`
2. "值得说明的是" 叙事段落——解释标的公司创始人的核心工作、定义的范式、突出特质（如最年轻团队、增长最快）。此段落**无固定模板**，根据实际数据撰写。
3. **一张大表格**（姓名 / 备注 / 总引用量 / 顶刊顶会&一二作引用量 / 主要研究方向），所有人按公司顺序排列，中间用**公司合计行**分隔。不要拆成多个小表格。
4. 研究方向相关性叙事，每公司一段解释，使用"高相关" / "分化显著"等标签。
5. 脚注说明数据来源和注意事项。

## 执行流程

### 第一步：发现Google Scholar主页

**Profile页爬取必须使用CDP浏览器自动化工具**（`agent-browser`、`browser-use`、`Stagehand`、Playwright等）。WebSearch / Tavily 只能用于本步骤（发现主页链接），绝不能用于提取引用数或论文列表，因为第三方聚合平台数据陈旧且不全。

对每个人：
1. 获取Google Scholar主页链接。发现步骤可以使用 **WebSearch** 或 **agent-browser**：
   - WebSearch查询：`<Name> Google Scholar robotics AI`
   - 或通过agent-browser打开：`https://www.google.com/search?q=<Name>+Google+Scholar+robotics+AI`
2. 提取第一个 `scholar.google.com/citations?user=` 链接。
3. 如名字常见导致歧义，添加提示词（`+MIT`、`+Stanford`、`+ALOHA`）重新搜索。两次尝试后仍歧义，再询问用户。

**反爬安全**：每次搜索间隔2-3秒。如Google显示异常流量/CAPTCHA：
- **交互模式**（正在与用户对话）：提供两个选项：
  - **选项A**：让用户启动Chrome远程调试（`chrome --remote-debugging-port=9222`），然后重连agent-browser到 `http://localhost:9222` 继续。
  - **选项B**：让用户手动粘贴每个主页的"All / Since 2021"引用数和前20篇论文列表。
- **自主模式**（如子agent）：不问用户。改为：
  1. 等待30秒后重试一次。
  2. 仍被拦截则回退到WebSearch / WebFetch / Tavily获取引用数和论文列表。
  3. 所有数字标注为估算值，并在脚注中说明回退情况。

### 第二步：通过浏览器自动化爬取Profile页数据

对每个确认的主页URL：
1. **用agent-browser打开主页**。
2. **提取侧边栏 totals**，使用JavaScript eval：
   ```js
   const rows = document.querySelectorAll('#gsc_rsb_st tbody tr');
   const allTime = rows[0]?.querySelectorAll('td')[1]?.innerText;
   const since2021 = rows[1]?.querySelectorAll('td')[1]?.innerText;
   ```
3. **提取完整论文列表**：
   - 论文行在 `#gsc_a_b .gsc_a_tr`。
   - 每行提取：
     - 标题：`.gsc_a_at`
     - 作者：`.gs_gray`（第一个匹配）
     - 会议/年份：`.gs_gray`（第二个匹配）
     - 引用数：`.gsc_a_c`
   - **反复点击"SHOW MORE"**直到全部加载。如列表极长，到约200篇时停止，并注明剩余未加载数量。
4. 将原始论文列表（标题、作者、会议、年份、引用数）保存到本地草稿文件，供交叉核对。

**为什么必须用浏览器自动化**：Google Scholar主页是动态的且反爬严格。第三方API（Semantic Scholar、OpenAlex）经常返回不完整或过时的数据。只有浏览器自动化能保证获取到实时的"All / Since 2021"侧边栏和完整的可见论文列表。

### 第三步：计算顶刊顶会&一二作引用量

这是最核心的计算步骤，规则必须严格执行：只有同时满足以下两个条件，论文的引用量才计入"顶刊顶会&一二作引用量"：

**条件1：发表在顶刊顶会上**
- 对照 `references/top_venues.md` 中的列表判断。
- 匹配时忽略大小写、标点、年份和卷号。
- 允许部分匹配（如 "Proceedings of Robotics: Science and Systems" 匹配 "RSS"）。
- 仅arXiv而无后续会议/期刊信息的，不算顶会。

**条件2：该学者是第一作者或第二作者**
- Google Scholar作者栏格式：`"T Zhao, C Chi, S Song"`。
- 逗号前第一个人是一作，逗号后第二个人是二作。
- 中文名：`"C Chi"` 对应 Cheng Chi，按姓氏和首字母匹配。

**操作流程**：
1. 逐篇遍历该学者的论文列表。
2. 对每篇先看会议是否命中顶刊顶会列表；再看该学者是否一作或二作。
3. 两个条件同时满足，把该论文引用数累加到"顶刊顶会&一二作引用量"。
4. 全部遍历后核对：累加结果必须 ≤ 该学者"总引用量"；如更高，说明计算有误，重新检查。
5. 把符合条件的论文单独列一个清单（标题 + 作者 + 会议 + 引用数），方便抽查核对。

### 第四步：研究方向与创业路线相关性分析

对每个人，阅读论文标题和会议。将核心论文分类为：
- **直接相关** — 标题/会议明确关于机器人/具身AI/灵巧操作/物理系统RL。
- **中等相关** — 基础方法（如通用RL、元学习、3D视觉）可服务于机器人但不是机器人专用。
- **低相关/噪声** — 纯NLP、纯视觉、生物学等，无明显机器人应用。

然后每公司写一小段总结：
- 高引用工作中有多少比例是直接相关的。
- 是否有创始人显示"职业转型"（早期做不相关领域，后来对齐）。
- 团队综合能力如何映射到其声明的产品方向。

### 第五步：年龄推断（条件触发）

**仅当标的公司创始人是所对比公司中最年轻的团队时，才执行此步骤**。如标的公司是最年轻的，启动年龄搜索，备注列写上年龄。

如标的公司是最年轻的：
1. 对每个创始人搜索 `https://www.google.com/search?q=<Name>+age+born+<school>`。
2. 如找到确切出生年份（如Wikipedia、可靠简历），记录。
3. 如未找到，从教育时间线推断：
   - 美国本科入学年龄约18岁。
   - 用最早可验证的学位开始年份推算出生年。
4. 将年龄插入表格**备注列**开头：`[Age]岁。`
5. 推断的年龄必须标"~"，并在脚注中说明推断依据。

### 第六步：组装Brief

严格按照 `references/output_template.md` 的章节顺序和表格格式组装。**模板固定不变**。不得新增章节，不得删减，不得改顺序。

**允许的章节（固定顺序）**：
1. 标题：`# [Company A] vs [Company B] vs [Company C] 学术对比Brief`
2. `## 创始成员学术影响力对比（论文引用量）`
   - 必须以三条必备排名语句开头。
   - 然后是"值得说明的是"叙事段落。
   - 然后是**一张大表格**：所有人按公司顺序排列，同公司人员连续排列，公司之间用**加粗的公司合计行**分隔。不要拆成多个小表格，不要加 `### [Company Name]` 子标题。
3. 研究方向相关性叙事（紧跟表格之后，不设标题）。
4. `## 说明` 脚注章节。

**严禁添加的内容**（无skill时baseline经常画蛇添足，你必须排除）：
- 技术谱系图 / 师承关系图（如"Russ Tedrake分支树"）
- 投资评分表 / 五星评级 / 护城河评分
- "看多/看空" 投资论点章节
- 执行摘要表格（排名语句本身就是摘要）
- 任何独立的"投资判断"、"关键投资论点"、"技术路线对比"大章节

表格规则：
- **一张大表格**，不要拆成多个小表格。所有人按公司顺序连续排列，公司之间用加粗的公司合计行分隔。
- **备注列**格式：`公司 Role，背景关键词`（如"Sunday Robotics CEO，Stanford, DeepMind, Tesla, Google X"）。如已调查年龄且标的公司为最年轻，则在开头加上年龄：`27岁。Sunday Robotics CEO，Stanford...`。
- **公司合计行**必须显示总引用量和顶刊顶会&一二作引用量之和。
- 以"说明"章节结尾。

## 质量检查

向用户返回最终markdown前：
1. 核对表格中每个数字都出现在原始爬取数据中（不得虚构引用数）。
4. 确认三条必备排名语句存在且准确。
5. 确认markdown表格语法正确。
6. **检查禁用内容**：搜索输出中是否出现以下关键词/结构，如出现则删除："技术谱系"、"师承"、"投资护城河"、"五星"、"看多"、"看空"、"执行摘要"、"投资判断"、"关键投资论点"。

## 配套资源

- `references/top_venues.md` — 顶刊顶会列表，用于判断哪些论文可计入「顶刊顶会&一二作引用量」。
- `references/output_template.md` — 输出结构和表格模板的严格参照。
