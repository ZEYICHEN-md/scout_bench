# VC 评分标准

> 本文件为阶段3（评分排名）的详细规则，SKILL.md 引用本文件。

---

## 信息来源与阶段判定依据

本评分标准中的**阶段区分**（Pre-seed / Seed / Series A 等）基于以下公开信息综合判定：

| 信息类型 | 典型来源 | 判定作用 |
|---------|---------|---------|
| **融资轮次与金额** | Yahoo Finance、Crunchbase、Linkedin、Business Wire、Tracxn、PRNewswire、公司新闻稿、TechCrunch、36Kr、Pulse 2.0、Pandaily | 直接确定公司当前融资阶段（Pre-seed / Seed / Series A / B 等） |
| **产品/商业化里程碑** | 公司官网 Blog、行业 benchmark 榜单、客户官方公告、LinkedIn | 判断 Traction 所处阶段：Demo → Pilot → 规模化部署 |
| **创始人履历** | LinkedIn、Google Scholar、公司官网团队页、学术主页 | 评估 Team 维度时，判断是否为首次创业、是否有成功退出 |
| **市场与赛道数据** | 行业研报、投行报告、咨询公司报告、权威媒体报道 | 支撑 Market 维度的 TAM 和增速估算 |
| **估值与投资人** | 融资新闻中的 post-money 估值、领投方知名度 | 评估 CapEff 时与同阶段同行业均值对比 |

**阶段打分的核心原则**：
- **同阶段同标准**：不会用 Series A 的收入标准去要求 Seed 公司，也不会因为 Pre-seed 尚未产生收入就系统性给低分
- **按赛道调整**：SaaS 公司以 ARR 为主；非 SaaS 公司（机器人、硬件、芯片、AI Lab）以部署量、数据量、benchmark 排名、头部客户签约为替代指标
- **信息不足时保守处理**：若无法确认公司阶段或某维度数据缺失，优先给出保守分，并在报告中注明

## 评分维度与权重

| 维度 | 权重 |
|------|------|
| 创始团队 (Team) | 30% |
| 市场机会 (Market) | 25% |
| 技术护城河 (Tech Moat) | 15% |
| 商业化进度 (Traction) | 20% |
| 资本效率 (Capital Efficiency) | 10% |

**总分计算**：加权平均，保留两位小数（四舍五入）。

```
总分 = Team × 0.30 + Market × 0.25 + Moat × 0.15 + Traction × 0.20 + CapEff × 0.10
```

---

## Team (30%)

| 分数 | 标准 |
|------|------|
| 10分 | 连续创始人+成功退出(≥$100M)；或 世界级学术声誉（顶会 best paper / 开源项目核心作者 / 师从图灵奖得主）+ 完整互补团队 |
| 8分 | 顶级大厂研究负责人（如 Google DeepMind 十年资深 + Gemini 负责人）；或 成功退出；或 顶级学术+强工业落地合伙人 |
| 6分 | 创始人背景扎实但团队不完整；或 大厂资深但非负责人级别 |
| 4分 | 背景一般或信息不足 |
| 2分 | 创始人背景有疑虑或信息严重缺失 |

**按阶段调整**：早期公司（Seed/Pre-seed）允许"联合创始人尚未全部到位"，但核心创始人本身必须能打；若核心创始人为首次创业的顶级学者，不因"无退出记录"而降档超过 1 分。

---

## Market (25%)

| 分数 | 标准 |
|------|------|
| 10分 | 万亿级市场，政策强力顺风，爆发拐点明确 |
| 8分 | 千亿级市场，赛道高速增长 |
| 6分 | 百亿级市场，增速明确 |
| 4分 | 市场存在但 TAM 有限 |
| 2分 | 市场过小或高度不确定 |

---

## Tech Moat (15%)

| 分数 | 标准 |
|------|------|
| 10分 | 专利/开源生态/数据网络效应，难以复制 |
| 8分 | 强技术差异化，有一定壁垒 |
| 6分 | 技术有一定壁垒但可复制 |
| 4分 | 技术护城河浅 |
| 2分 | 无护城河或极易被复制 |

---

## Traction (20%)

### SaaS / 软件公司

| 分数 | 标准 |
|------|------|
| 10分 | ARR > $10M，持续增长 |
| 8分 | ARR $1M–$10M，有明确付费客户 |
| 6分 | 种子轮但有明确的商业化信号（合同/试点/POC） |
| 4分 | 有用户但商业化不清晰 |
| 2分 | 早期，无明确商业化数据 |

### 非 SaaS 公司（机器人、硬件、芯片、AI 研究 Lab 等）

| 分数 | 替代指标 | 典型对应阶段 |
|------|----------|-------------|
| 10分 | 大规模商业部署（如数万台产线落地）+ 头部客户复购 | Series B 及以后 |
| 8分 | 头部客户签约（如 Fortune 500 / 行业龙头）+ 明确合同金额 | Series A |
| 6分 | 试点/POC 落地 + 行业 benchmark 领先 | Seed 轮 |
| 4分 | Demo 验证完成（如视频演示、实验室测试、早期原型），但无商业化合同 | Pre-seed |
| 2分 | 纯概念/论文阶段，无落地信号 | 极早期 / 刚成立 |

**非 SaaS 典型替代指标**：
- 商业部署数量 / 生产线落地数量
- 数据飞轮规模（如 20万小时交互数据）
- 行业 benchmark 排名（如 RoboChallenge #1）
- 头部客户签约（如 CATL、Figure AI）

**阶段调整说明**：
- **Seed 轮**机器人公司：只要有 1–2 条产线试点或行业 benchmark 领先，即应给 6 分，不要求 Fortune 500 签约
- **Series A** 机器人公司：必须有可验证的头部客户合同或规模化部署数据，才能给 8 分及以上
- **Pre-seed** AI 研究 Lab：首个模型未发布、无收入是正常状态，有 Demo 视频或学术验证即可给 4 分

---

## Capital Efficiency (10%)

| 分数 | 标准 |
|------|------|
| 10分 | 估值与里程碑高度匹配，超额认购，顶级投资人 |
| 8分 | 估值合理，知名 VC 背书 |
| 6分 | 估值与行业均值持平 |
| 4分 | 估值偏高但有合理解释 |
| 2分 | 估值严重虚高或信息不透明 |

---

## 信息不足的处理规则

若某维度完全搜不到公开信息：
- **优先策略**：给出保守估计分，并在 investment_analysis.md 的 Verdict 中注明"（该维度公开信息不足，分数偏保守）"
- **备选策略**：给出范围分（如 3–5 分），总分计算时取中值（4 分）
- **禁止**：凭感觉打满分或凭猜测打高分

## 评级定义与总分映射

| 评级 | 定义 | 总分区间 |
|------|------|----------|
| **S Tier** | 顶级创始人 + 明确 PMF + 宽广赛道 + 融资强劲 + 执行力已验证 | ≥ 8.0 |
| **A Tier** | 创始人强 OR 市场强，有可验证的执行信号，无明显短板 | 7.0 – 7.9 |
| **B Tier** | 某方面突出但存在明确短板，执行风险可控 | 5.5 – 6.9 |
| **C Tier** | 有机会但执行风险高或信息不足，需要更多验证 | 4.0 – 5.4 |
| **D Tier** | 基本面薄弱，不建议跟投 | < 4.0 |

**边界处理**：
- 若总分为 7.95，四舍五入为 8.0，评级 S Tier
- 若某公司有单项 2 分（如信息严重不透明），即使总分在 C Tier 区间，也可在备注中建议"降一档观察"

## 排名表规则

**CONFIRMED 和 UNCLEAR 公司均进入表格**，NOT_CHINESE 不进入。

### CONFIRMED 公司
- 正常显示五维度分数、总分、评级
- 按总分降序排列

### UNCLEAR 公司
- 分数和评级列全部填 `-`
- 在"已知信息摘要"列中，基于阶段1搜索结果用一句话总结：
  - 公司 tagline（如有）
  - 创始人姓名/背景线索（如有）
  - 信息缺口（如"待 LinkedIn 验证" / "搜索数据不足"）
- 不占用排名序号，列在 CONFIRMED 公司之后

### NOT_CHINESE 公司
- 不进入 VC 排名表
- 仅在筛查摘要中单独列出数量和名单

## 评分计算示例

**Spirit AI 总分计算**：
- Team: 9.0 × 0.30 = 2.70
- Market: 9.0 × 0.25 = 2.25
- Moat: 8.0 × 0.15 = 1.20
- Traction: 7.0 × 0.20 = 1.40
- CapEff: 7.0 × 0.10 = 0.70
- **总分 = 8.25** → **S Tier**

**Marr Labs 总分计算**（Seed 轮，按 SaaS 评估 Traction）：
- Team: 7.0 × 0.30 = 2.10
- Market: 6.0 × 0.25 = 1.50
- Moat: 5.0 × 0.15 = 0.75
- Traction: 5.0 × 0.20 = 1.00
- CapEff: 7.0 × 0.10 = 0.70
- **总分 = 6.05** → **B Tier**
