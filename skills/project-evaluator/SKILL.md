# 项目评估 Skill

基于"5维度16项检测点"框架，对投资项目进行系统化评估。

## 工作流程

1. **信息收集**：使用 web_search 搜索项目，每次搜索必须获取**可验证的具体数据**（数字、日期、合作方名称、榜单成绩）
2. **逐维度评估**：加载 [evaluation-framework.md](references/evaluation-framework.md)，按照16项检测点逐一评分
   - **关键原则**：没有公开数据支撑的检测点，该项得0分，**不作讨论**
   - 禁止使用"信息不公开"、"有待验证"等描述；直接缺省
3. **输出报告**：仅输出有数据支撑的评估内容，结构精简：
   - 融资与资本（金额、投资方、日期）
   - 技术与产品（参数、benchmark分数、价格）
   - 商业化（合作客户、应用场景）
   - 团队背景（履历、过往成绩）
   - 综合评分 + 投资建议

**核心要求**：废话不写，每一句话都必须有数据或来源支撑。

## 使用方式

```
评估项目 [项目名称]
分析 [公司名称] 的投资价值
对 [项目] 进行尽调评估
```

## 评估框架

详细评估标准和评分规则见 [references/evaluation-framework.md](references/evaluation-framework.md)。

**5维度概览**：
- 团队与创始人特质（4项检测点，满分20分，权重25%）
- 市场机会与赛道红利（3项检测点，满分15分，权重20%）
- 产品与技术壁垒（3项检测点，满分15分，权重25%）
- 商业模式与财务模型（3项检测点，满分15分，权重20%）
- 资源整合与交易生态（3项检测点，满分15分，权重10%）

**总分80分，投资建议等级**：
- S级（70-80分）：强烈推荐
- A级（60-69分）：推荐
- B级（50-59分）：观察
- C级（40-49分）：谨慎
- D级（<40分）：不推荐
