# 项目评估 Skill

基于"5维度16项检测点"框架，对投资项目进行系统化评估。

## 工作流程

1. **信息收集**：使用 web_search 搜索项目相关信息
   - 项目/公司名称 + "融资"、"估值"、"创始人"、"团队"
   - 项目/公司名称 + "产品"、"技术"、"商业化"
   - 项目/公司名称 + "市场"、"赛道"、"竞争对手"
   - 创始人/核心团队成员背景

2. **逐维度评估**：加载 [evaluation-framework.md](references/evaluation-framework.md)，按16个检测点逐一分析打分

3. **输出报告**：生成结构化评估报告，包含：
   - 各维度得分和评语
   - 加权总分和投资建议等级
   - 核心亮点与风险提示

## 使用方式

```
评估项目 [项目名称]
分析 [公司名称] 的投资价值
对 [项目] 进行尽调评估
```

## 评估框架

详细评估标准和评分规则见 [references/evaluation-framework.md](references/evaluation-framework.md)。

**5维度概览**：
- 团队与创始人特质（4项检测点，满分20分，权重25%）
- 市场机会与赛道红利（3项检测点，满分15分，权重20%）
- 产品与技术壁垒（3项检测点，满分15分，权重25%）
- 商业模式与财务模型（3项检测点，满分15分，权重20%）
- 资源整合与交易生态（3项检测点，满分15分，权重10%）

**总分80分，投资建议等级**：
- S级（70-80分）：强烈推荐
- A级（60-69分）：推荐
- B级（50-59分）：观察
- C级（40-49分）：谨慎
- D级（<40分）：不推荐
