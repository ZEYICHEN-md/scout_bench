# scout_bench

A collection of Claude Code skills for various research and analysis workflows.

## Skills

| Skill | Description |
|-------|-------------|
| `exa-company-miner` | Company research and data extraction |
| `researcher-eval` | Researcher evaluation utilities |
| `sector-prospector` | Industry sector prospecting and analysis |
| `startup-tracker` | Startup tracking and screening |
| `team-academic-comp` | Team academic competition research |
| `weekly-recommendation` | Weekly recommendation generation |

## Usage

These are [Claude Code skills](https://docs.anthropic.com/en/docs/skills). Place them in your `.claude/skills/` directory or load them via the Claude Code CLI.

## Status

This repo is a work in progress — skills will be added and updated over time.
